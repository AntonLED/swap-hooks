# UU Flow Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add deterministic uninformed-user (UU) flow per
`docs/superpowers/specs/2026-08-09-uu-flow-design.md`, with the discrete-mode
groundwork, the trade-time metrics, and the MEVChargeHook fee-box clamp.

**Architecture:** Python generates a per-candle UU volume trace from Binance
quote volumes (κ-normalized); the Forge harness computes the participation
`P = exp(-λ|r|)` at runtime from pool state and executes thinned UU swaps before
the arbitrage check; Python metrics become trader-aware and gain a trade-time
valuation.

**Tech Stack:** Foundry (forge test harness in `contracts/test/Replay.t.sol`),
Python via `uv` (pandas, pytest), existing JSONL event pipeline.

## Global Constraints

- **NEVER `git commit` or `git push`.** The repository owner commits everything
  personally. Leave all changes in the working tree.
- Run Python only through `uv run ...`; never bare `python`/`pip`.
- Foundry lives at `~/.foundry/bin`; export `PATH="$HOME/.foundry/bin:$PATH"` in
  every shell that calls `forge`.
- Solidity tests: `cd contracts && forge test`. Python tests: `uv run pytest -q`
  from the repo root. Both suites green before a task is done.
- Formatting at the end of all work: `npm run format` (Prettier) and
  `npm run format:sol` (forge fmt). Do not reformat unrelated files.
- Policy contracts under `contracts/src/*.sol` must not change behaviorally. New
  code goes in `contracts/src/libraries/`, `contracts/test/`, `experiments/`.
- Wei-scale sums in Python: always `metrics.exact_sum`, never `Series.sum()`
  (int64 overflow wraps silently).
- The arb-only results under `results/` are frozen artifacts. Nothing in this
  plan may overwrite them; new runs go to fresh directories.
- Fee units: Uniswap v4 fees are **pips** (hundredths of a bp); 1e6 pips = 100%.
  `MEVChargeHook.config.feeMax` is in **bps** (its 1000 produced 100000-pip
  fees). Chainlink prices are 1e8-scaled; token amounts and WAD math are 1e18;
  sqrt prices are X96.
- Canonical constants: `UU_LAMBDA_WAD = 231_049_060_186_648_440_000` (=
  ln(2)/0.003 · 1e18, "half the flow walks at 30 bps total cost"); basket
  20,000,000 USDT; calibration year `[1704067200000, 1735689600000)` (2024 UTC).

### Task 2: UU trace generator (`experiments/uu.py`)

**Files:**

- Create: `experiments/uu.py`
- Test: `tests/test_uu.py`

**Interfaces:**

- Produces:
  - `uu_profile(*volume_frames: pd.DataFrame) -> pd.DataFrame` — columns
    `open_time, v_usdt` where `v_usdt` is the geometric mean of the given legs'
    `quote_volume` (one frame for USDC/USDT, two otherwise). Frames are already
    aligned by the caller (`align_traces`).
  - `kappa(profile: pd.DataFrame, basket_usdt: float) -> float` — scale such
    that κ·(mean daily Σ v_usdt) = basket_usdt.
  - `export_uu_trace(profile, kappa, path, mode="share", seed=0, sigma=1.0) -> None`
    — writes headerless CSV
    `open_time,size_ab_wad,u_ab_wad,size_ba_wad,u_ba_wad` (all ints; sizes in
    USDT·1e18).

Trace semantics (consumed by Task 4): per candle and direction, `size` is the
potential UU volume in USDT-wad and `u` a WAD uniform draw. Mode `share` writes
`size = κ·v/2`, `u = 0`; the harness thins multiplicatively
(`amount = size · P`). Mode `discrete` writes one lognormal potential trade per
direction, `size = (κ·v/2)·exp(σZ − σ²/2)` with `Z ~ N(0,1)` from
`numpy.random.default_rng(seed)`, `u = ⌊U(0,1)·1e18⌋`; the harness executes
all-or-nothing (`amount = size` iff `u ≤ P·1e18`). Same file format, one loader.

**Files:**

**Interfaces:**

- Produces (all `internal` library functions):

    the exp core from solady's `FixedPointMathLib.expWad` (MIT), with an
    attribution comment; inputs below −41.45e18 return 0.

    `r ≥ 0`, else `expNegWad(−|λ·r|/1e18)` per spec §2 (the two-branch P).

`_step`): per candle, after `_setFeeds`/roll/warp, run `_uuStep(i)` **before**
`_step(i)`. `_uuStep` does, for side A→B then B→A:

```solidity
function _uuStep(uint256 candle) internal {
    if (!uuEnabled) return;
    for (uint256 side = 0; side < 2; side++) {
        bool zeroForOne = side == 0;
        (uint256 sizeWad, uint256 uWad) = _uuTraceAt(candle, zeroForOne);
        if (sizeWad == 0) continue;
        (uint160 s,,,) = poolManager.getSlot0(poolId);
        uint256 extPriceX96 = FullMath.mulDiv(price0[candle], Q96, price1[candle]);
        uint24 fee = _feeForSender(_uuSender(candle, zeroForOne), zeroForOne); // snapshot-wrap like _executeArb's logging reads
        int256 r = UUMath.rWad(s, extPriceX96, fee, zeroForOne);
        uint256 p = UUMath.participationWad(r, uuLambdaWad);
        uint256 usdtWad = uuDiscrete ? (uWad <= p ? sizeWad : 0) : FullMath.mulDiv(sizeWad, p, 1e18);
        if (usdtWad == 0) continue;
        // USDT-wad -> input token units at the candle's external price
        uint256 amountIn = FullMath.mulDiv(usdtWad, PRICE_SCALE, zeroForOne ? price0[candle] : price1[candle]);
        if (amountIn == 0) continue;
        _executeUU(candle, zeroForOne, fee, amountIn, s, r, p);
    }
}
```

`_executeUU` mirrors `_executeArb` (fund, prank, swap, measure gas, log with
`trader="uu"`, `expectedProfit=0`, skip when `candle < warmupCandles` or
`!logging`) with sender
`address(uint160(uint256(keccak256(abi.encode("uu", candle, zeroForOne)))))`.
The MEVCharge logging-read hazard documented at `_executeArb` applies

snapshot/revert/delete pattern. **Critical detail:** the fee used for `r` must
be read via a state snapshot too (MEVChargeHook's `_getFee` writes history). The
trace loader `_loadUuTrace` parses the 5-column CSV into four storage arrays;
`require` its length equals `price0.length`.
